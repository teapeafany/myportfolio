Heavenly Lyre

An Arduino MIDI lyre with invisible strings

This project is probably one of the coolest artifacts I have ever made by far. I came across the concept of a laser harp while surfing online, and, while it wasn't the most common creation, the creator I was looking at had confirmed in the comments that she used a MIDI connection and Arduino, so I knew it could be done. I wanted to create this musical instrument for myself. The lack of strings on the instrument seemed magical and I thought it would be a perfect prop for Harry Potter, as they have enchanted instruments, and I can certainly envision it being used on set. Because of a harp's asymmetrical shape and the fact that I wasn't entirely familiar with using a harp (I have only ever played the oboe and piano) I figured I wanted something simple and symmetrical (easy to CAD) for my instrument. I immediately thought of a lyre—inspired by the game Genshin, funny enough.

The Research & Testing

The concept was simple: lasers would act as invisible strings, beaming down on photoresistors, which would detect some light value. Once the player blocks a beam, the light value will decrease, and I would need to somehow send this indication to the digital music software on my computer. I did a lot of research and the following article helped a lot in this understanding.

My reference for understanding circuitry:

https://www.instructables.com/Arduino-Laser-Harp-1/

While the parts and schematics were quite different for me, the concepts were the same.

I knew this would be an incredibly multidimensional assignment needing several parts, so I made sure to start early. I first got my hands on the lasers and photoresistors (thanks to Chase and Professor Nitsche!) and tested them out. Once I got those working, I knew I could proceed with this idea.

3D Modeling

I then got started on the CAD as I knew printing would take a while. There were many models of Venti's lyre online, but after deliberation and a lot of struggle to edit the mesh body model, I decided to create my own model, as I would need certain elements to hide my Arduino and accommodate for wiring and holes. As I had never used Fusion before, I had to learn a lot to CAD my model this time. It really wouldn't be as simple as the table in my previous project. From using reference images, spline, extruding, I had to get the crash course from a friend (thanks Tanmay!). We tried different models and measurements and sent the STL to another friend of mine who had a 3D printer. Since HIVE tends to have long queues, it was extremely helpful to have an outside printer source.

Our first CAD model came with a base—14 inches tall and 1.5 inches thick. I was hit with my first limitation: I was told it was too big for the available printer and had to be much thinner. I ended up deciding that making the protoboard and Arduino all fit inside was but a pipe dream and I would have to keep things moderately external. Which was workable.

I made adjustments and the final dimensions ended up being:

  • Top holes (for lasers with 6mm diameter): 6.3mm (for tolerance)
  • Bottom holes (for lasers to not fall through): 4.7mm
  • Height of lyre: 10 inches
  • Bottom holes for photoresistors: around 5mm

The bottom of the lyre was hollow for the photoresistor wiring. Finally the model was done and I sent it off to be printed (took a whooping 8 hours).

MIDI Bridge and Code

This took me a day to just figure out. I was looking for Hairless MIDI Bridge to connect the Arduino to GarageBand and found out the one everyone kept recommending isn't compatible with the new Mac software. I had to find an alternative.

Summary of the journey

  1. Started with Serial-MIDI Bridge — Downloaded SerialMidiBridge app, bypassed Mac security warning, set port to /dev/cu.usbmodem101, baud rate 9600, IAC Driver Bus 1. Clicked Start but GarageBand never received any notes.
  2. Checked everything — Verified IAC Driver was online in Audio MIDI Setup, confirmed Bus 1 port existed, GarageBand showed "1 MIDI Input detected," MIDI Monitor showed IAC Driver Bus 1 was active. But blocking the laser triggered nothing in GarageBand.
  3. Found the real problem — Opened Serial Monitor while blocking laser, saw garbage characters (Arduino was sending bytes). But MIDI Monitor showed nothing arriving. Conclusion: Serial-MIDI Bridge wasn't converting the data properly.
  4. Tried alternatives — Hairless MIDI site was down. MIDIUSB library didn't work (Arduino Uno doesn't support USB MIDI). Serial-MIDI Bridge baud rate didn't support 31250 (true MIDI rate).
  5. Pivoted to Python — Set threshold at 600, block laser → NOTE ON, unblock → NOTE OFF. Installed pyserial and python-rtmidi. Wrote a Python script to read serial data and send MIDI directly to IAC Driver. First attempt sent raw bytes as MIDI, got garbage. Switched to reading LDR values as text numbers. And Python worked!

To run: python3 ~/serial_midi.py. The script auto-reconnects to the Arduino since I kept having disconnect issues.

Python script:

import serial
import rtmidi
import time

midiout = rtmidi.MidiOut()
midiout.open_port(0)

THRESHOLD = 600
last_notes = []

def connect():
    while True:
        try:
            ser = serial.Serial('/dev/cu.usbmodem101', 9600, timeout=1)
            time.sleep(2)
            ser.reset_input_buffer()
            print("Connected!")
            return ser
        except:
            print("Waiting for Arduino...")
            time.sleep(2)

ser = connect()
print("Running... block the lasers!")

while True:
    try:
        line = ser.readline().decode('utf-8').strip()
        if line:
            values = list(map(int, line.split(',')))
            if len(values) != 4:
                continue

            b1 = values[0] < THRESHOLD
            b2 = values[1] < THRESHOLD
            b3 = values[2] < THRESHOLD
            b4 = values[3] < THRESHOLD

            if b1 and b2 and b3 and b4:
                notes = [83]
            elif b1 and b2 and b3:
                notes = [77]
            elif b1 and b2 and b4:
                notes = [73]
            elif b1 and b3 and b4:
                notes = [75]
            elif b2 and b3 and b4:
                notes = [80]
            elif b1 and b2:
                notes = [72]
            elif b1 and b3:
                notes = [74]
            elif b2 and b3:
                notes = [69]
            elif b3 and b4:
                notes = [70]
            elif b2 and b4:
                notes = [80]
            elif b1 and b4:
                notes = [73]
            elif b1:
                notes = [71]
            elif b2:
                notes = [76]
            elif b3:
                notes = [79]
            elif b4:
                notes = [78]
            else:
                notes = []

            for note in last_notes:
                if note not in notes:
                    midiout.send_message([0x80, note, 0])
            for note in notes:
                if note not in last_notes:
                    midiout.send_message([0x90, note, 127])
                    print("NOTE ON:", note)

            last_notes = notes

    except:
        print("Disconnected! Reconnecting...")
        time.sleep(1)
        ser = connect()

Arduino code:

void setup() {
  Serial.begin(9600);
}

void loop() {
  int ldr1 = analogRead(A0);
  int ldr2 = analogRead(A1);
  int ldr3 = analogRead(A2);
  int ldr4 = analogRead(A3);
  
  Serial.print(ldr1); Serial.print(",");
  Serial.print(ldr2); Serial.print(",");
  Serial.print(ldr3); Serial.print(",");
  Serial.println(ldr4);
  
  delay(50);
}

Note: You have to close Arduino before running Python, and vice versa. This code works for four lasers and photoresistors!

Circuits and Soldering

I then needed to put together the rest of the lyre strings and solder it to the protoboard. This took a bit of planning, but since it wasn't my first time, I was comfortable with soldering and prepared a lot to solder efficiently. When I got my hands on the 3D model, I immediately tested all the parts together. And when it fit right, I began soldering.

I made sure to prepare all the wire lengths and strip them before I began to organize things well. Then I soldered all the photoresistors, resistors, and AX pins to the board, along with ground and 5V pins.

Note: Do not solder the legs of the photoresistors before putting them through the holes—because I forgot this I had to solder even more wire to connect them to the board. Not the worst, but did take a bit of time.

Then began the soldering of the lasers… This was honestly more of a struggle than it should've been. I was trying to solder all the lasers to two wires, one positive one negative, and I had to solder and desolder a few times. The wire ended up being too short after I had to cut and redo it a few times, which made it kind of stick out in the final, when I had intended on taping it to the sides of the lyre.

When I got all four working properly, I knew I was approaching the end. I secured everything with hot glue (to make sure the lasers don't move and stay right above the photoresistors). It was also useful to hot glue any parts that accidentally fell off the protoboard when I handled it too hard (which is something I wish I knew about for the cat project).
